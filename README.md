A two-line robot confession. The robot set an alarm for 6 p.m.
instead of 6 a.m., its person slept until noon and missed a
sister's graduation ceremony, and the lesson it draws is to say
the time back in plain words and wait for a yes before setting
any alarm again. The program validates the two lines (exactly
two lines, 1 to 400 characters, each ending as a sentence),
writes them to /output/entry.txt, and reads the file back to
check it matches.

## Run it

```sh
python3 main.py
```
